# js_com_docs — NGINX JS DOM Documentation

User-facing documentation for the NGINX JS DOM programmable-proxy layer.
Covers the JavaScript API from a developer's perspective: how to use it,
what each feature does, and complete working examples.

For the internal C implementation — data structures, wire formats, and
architectural rationale — see [`js_dom_doc_tech/`](../js_dom_doc_tech/README.md).

---

## Document Index

### Core Manual

| Document | Description |
|---|---|
| [js-dom-manual.adoc](js-dom-manual.adoc) | **Main developer manual** (~4000 lines). Comprehensive reference covering every feature: quick-start, request handlers, COM tree, dynamic reconfiguration, Workers, SharedWorkers, SharedArrayBuffer, L4 filters, plugin system, admin REPL, resource limits, third-party module integration, and a full API reference. |

### Topic Guides

| Document | Description |
|---|---|
| [js-filters-guide.adoc](js-filters-guide.adoc) | Header and body filters in depth. Five execution modes (whole-body sync/async, streaming sync/async, async generator). `addBodyFilter`, `addResponseHook`, `sendBuffer`. Examples for gzip expansion, HTML injection, and JSON transformation. |
| [js-pilgrim-guide.adoc](js-pilgrim-guide.adoc) | Full-proxy programming guide. Request-phase hooks (P1/P2/P3), upstream filters (P14), accept hooks (P4), L4 stream filters (P6/P13), cross-worker shared state, master lifecycle events, module system (P7/P16/P18). |

### Dynamic Reconfiguration Guides

A series of focused guides on the write side of the COM API — mutating live
nginx configuration from JavaScript without a reload.

| Document | Scope |
|---|---|
| [js-reconfig-guide.adoc](js-reconfig-guide.adoc) | Single-worker mutations: `write_mode`, `read_mode`, `snapshot()` / `restore()`. The fundamental building block. |
| [js-reconfig-guide-global.adoc](js-reconfig-guide-global.adoc) | Global `nginx.*` namespace: `nginx.version`, `nginx.log`, `nginx.cycle`, `nginx.events`, `nginx.broadcast`, `nginx.setTimeout`, `nginx.suspendAcceptance`, `nginx.suspendAllWorkers`. |
| [js-reconfig-guide-http.adoc](js-reconfig-guide-http.adoc) | `nginx.http` object: server and location config, handler installation, upstream management. |
| [js-reconfig-guide-servers.adoc](js-reconfig-guide-servers.adoc) | Server-level reconfiguration: `nginx.http.servers[]`, `server.addHook`, virtual-host management. |
| [js-reconfig-guide-locations.adoc](js-reconfig-guide-locations.adoc) | Location-level reconfiguration: `nginx.http.servers[].locations[]`, handler assignment, filter installation. |
| [js-reconfig-guide-all-workers.adoc](js-reconfig-guide-all-workers.adoc) | Propagating mutations across all workers atomically via `suspendAllWorkers` + `broadcast`. |
| [js-reconfig-guide-checkpoint.adoc](js-reconfig-guide-checkpoint.adoc) | Config checkpoint and rollback: taking point-in-time snapshots, restoring on failure, coordinating across workers. |

## Building the Docs

```bash
# HTML (requires asciidoctor)
asciidoctor js-dom-manual.adoc

# PDF (requires asciidoctor-pdf)
asciidoctor-pdf js-dom-manual.adoc

# FictionBook (requires Python 3)
python3 html2fb2.py js-dom-manual.html js-dom-manual.fb2
```
