  nginx.http.addServer(opts) — accepts:
  - listen[] — array of listen address strings
  - serverNames[] — array of server_name strings
  - locations[] — optional inline array of {path, root?, return?} objects

  srv.addLocation(path[, opts]) — returns this for chaining; opts supports root
  and return.

  How it works: Servers are collected into a pool-allocated ngx_array_t during
  JS_Eval. After the script returns (and only if it didn't throw), each pending
  server is serialized into a server{} ... } config snippet, written to a temp
  file, and fed to ngx_conf_parse() — the same mechanism as config.write(). This
   means the new servers get nginx's full merge/init_locations/optimize_servers
  treatment automatically.

● Done. Here's what was implemented and the key subtlety:

  nginx.http.delServer(name) — removes a server by server_name. The tricky part
  was that removing only from cmcf->servers wasn't enough: the listen directive
  had already registered the server in cmcf->ports[].addrs[].servers. Without
  also removing it there, ngx_http_optimize_servers would still bind the port
  with a null default_server. The fix: compact the server out of every
  addr->servers, then prune empty addrs from their port, then prune empty ports
  from cmcf->ports.

  nginx.http.delLocation(serverName, path) — uses ngx_queue_remove() on the raw
  location queue. Safe because location trees haven't been built yet when
  js_init_http fires.

  Both return the count of removed items (0 if nothing matched).

● Done. Summary of what was implemented:

  nginx.http.modServer(name, opts) — finds all servers whose server_names
  include name, replaces their entire server_name list with opts.serverNames[].
  New names are pool-allocated ngx_http_server_name_t entries; the existing
  array is cleared and repopulated before ngx_http_server_names() builds the
  virtual-host hash.

  nginx.http.modLocation(serverName, path, opts) — finds all locations matching
  path in the named server and applies:
  - opts.path — renames clcf->name in-place (lq->name is a pointer into it, so
  the queue entry updates automatically)
  - opts.root — replaces clcf->root and clears root_lengths/root_values so nginx
   uses the plain string path

  Both are safe at js_init_http time because location trees haven't been built
  yet.
