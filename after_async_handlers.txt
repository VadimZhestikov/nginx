│ Plan: Real async handlers via NGINX event-loop integration                   │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ The current module already handles async handlers whose Promises settle      │
│ synchronously (drain JS_ExecutePendingJob before returning). However,        │
│ handlers using a real timer (await nginx.setTimeout(10)) leave the Promise   │
│ PENDING after the drain and currently return 500.                            │
│                                                                              │
│ This plan adds:                                                              │
│ 1. nginx.setTimeout(ms) — a JS function that returns a Promise resolved by   │
│ an NGINX ngx_event_t timer after ms milliseconds.                            │
│ 2. Request suspension — when the handler's outer Promise is still PENDING    │
│ after                                                                        │
│ the job drain, suspend the nginx request (r->main->count++, return           │
│ NGX_DONE) and register it in the worker for later resumption.                │
│ 3. Resume — when the timer fires, drain jobs, and finalize the suspended     │
│ request.                                                                     │
│                                                                              │
│ Scope: one suspended async request per worker at a time (the single-slot     │
│ async_pending field). Multiple concurrent async requests require a linked    │
│ list; that is a follow-up.                                                   │
│                                                                              │
│ Architecture                                                                 │
│                                                                              │
│ JS call path (in worker event loop):                                         │
│   ngx_js_content_handler                                                     │
│     JS_Call(fn) → handler returns Promise P (PENDING)                        │
│     JS_ExecutePendingJob* → jobs drained, P still PENDING                    │
│     → suspend: r->main->count++, w->async_pending = actx, return NGX_DONE    │
│                                                                              │
│ nginx timer path (later, in same event loop):                                │
│   ngx_js_timer_handler (ev->handler)                                         │
│     JS_Call(resolve, undefined) → P1 (setTimeout promise) resolves           │
│     JS_ExecutePendingJob* → async body resumes, calls req.respond(), P       │
│ settles                                                                      │
│     ngx_js_async_check(w)                                                    │
│       reads req_op->responded / respond_rc                                   │
│       JS_FreeValue(req_obj, promise)                                         │
│       ngx_http_finalize_request(r, NGX_DONE)                                 │
│                                                                              │
