  Stage 23 proposal — r.cookies (parsed Cookie header)

  Expose r.cookies as a read-only plain JS object containing decoded cookie name/value pairs parsed from the Cookie request header. Splits on ; , each pair on =, trims whitespace, no URL decoding
  (cookies use their own encoding conventions).

  Example: Cookie: session=abc; theme=dark → {session: "abc", theme: "dark"}.

  Test: t/js_com_request_cookies.t — single cookie, multiple cookies, absent Cookie header, cookie with = in value.
