 Stage 13j proposal — userid (ngx_http_userid_filter_module)

  Exposes the user tracking cookie configuration as location.userid:

  ┌──────────┬───────────────────────┬────────────────┐
  │ Property │         Type          │   Directive    │
  ├──────────┼───────────────────────┼────────────────┤
  │ enable   │ "on"/"off"/"log"/"v1" │ userid         │
  ├──────────┼───────────────────────┼────────────────┤
  │ name     │ string                │ userid_name    │
  ├──────────┼───────────────────────┼────────────────┤
  │ domain   │ string                │ userid_domain  │
  ├──────────┼───────────────────────┼────────────────┤
  │ path     │ string                │ userid_path    │
  ├──────────┼───────────────────────┼────────────────┤
  │ expires  │ number (seconds)      │ userid_expires │
  ├──────────┼───────────────────────┼────────────────┤
  │ p3p      │ string                │ userid_p3p     │
  ├──────────┼───────────────────────┼────────────────┤
  │ mark     │ string (hex char)     │ userid_mark    │
  └──────────┴───────────────────────┴────────────────┘

  Built-in by default (no --with-* needed). Shall I proceed?
